# Robotics-Foundation-Lab3-Experiments
Robotics Foundation – Arduino Lab Experiments

About the Project

This repository contains six practical experiments completed as part of the Robotics Foundation course . The experiments were implemented using Arduino Uno and the Wokwi Simulator to explore basic electronics, sensor interaction, and Arduino programming.

Experiments Overview

The experiments cover the following topics:

1. LDR Sensor Readings and Calibration: Reading light intensity, calibrating sensor values, and applying the averaging method.
2. Threshold-Based Light Detection: Detecting darkness using a threshold value and controlling an LED.
3. Start/Stop Button Control: Using a push button to enable and disable the system’s response.
4. Three-Level Light Indicator: Identifying bright, dim, and dark conditions using an LDR sensor and two LEDs.
5. Dark-Event Counter: Counting transitions from a non-dark condition to a dark condition.
6. Digital Light Detection: Exploring the analog and digital outputs of an LDR sensor.
